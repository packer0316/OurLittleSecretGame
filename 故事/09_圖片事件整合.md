# 圖片事件整合

2026-11-20。本文供製作與驗收，含完整劇透。

33 張線索圖、13 張劇情圖均已接入遊戲。使用靜態圖片配合 HTML 證物全文、對話與旁白；沒有生成影片。原有移動、解謎、追逐、送行操作與三種結局仍由玩家完成。

## 玩家如何看到

- 按 E 調查物件：顯示對應實物圖、圖說及原有完整線索。六人童年合照沿用原圖與塗臉遮罩。
- 關鍵對話：圖片在該句揭露時出現，後續同段對話保留圖片。不是一開始把全部劇情圖輪播完。
- 送行事件：畫面以圖片與短對話停住，玩家按「繼續」後回到 3D 操作。讀圖期間不消耗點名或鑰匙挑戰時間。
- 點「查看大圖」開啟完整圖片，Esc 只關大圖，不會順便選擇對話。
- J 筆記 →「回看影像紀錄」：僅列出曾見圖片；回看不重播追逐、不改變選擇、不重做送行。
- 圖片載入失敗時保留線索全文與選項，仍可通關。

## 存檔與檔案

- `src/story/illustrations.js` 讀取公開 manifest 的文字索引，圖片本身只在顯示時下載。
- `Story.js` 管理圖文、放大、回看；`HomeStory.js`、`RoadStory.js` 接序章事件；`finale.js` 接送行段落。
- `state.pictures` 是獨立的已見圖片 ID 清單，未知 ID 與重複值會被過濾。舊版存檔沒有此欄位時預設空陣列，仍可繼續原進度；重讀物件可補入圖片。
- 結局後將已見圖片合併回最後抉擇的安全存檔，不把演出半途當作續玩位置。回到抉擇與重新載入都保留影像紀錄。
- 18 張真人三視圖留在美術圖冊供建模，不加入玩家線索收藏，也不代表已替換遊戲內所有 3D 人物。
- 紅布全遮眼、擔架與腳接地、正常手機比例三項修正版，均以選用清單中的 WebP 接入。

## 驗證

```powershell
npm test
npm run build
# 先在另一個終端啟動 npm run dev -- --host 127.0.0.1 --port 5178
node scripts/story-illustrations.mjs
npm run test:story
node scripts/story2-beats.mjs
```

`story-illustrations.mjs` 走過住處→山村→寺廟事件，檢查全部 46 張圖片解碼、時機、放大按鍵、存檔回看、結局暫停與重試、缺圖降級，以及 800px／390px 寬度。C 的完整操作與 A/B 分支另由既有 smoke／branches 測試覆蓋。截圖與機器可讀結果保存在 `artifacts/visual-integration/`。

正式子目錄部署可用 `STORY_URL` 指向含 base path 的 preview 伺服器，重跑相同測試；圖片路徑不依賴網站根目錄。
