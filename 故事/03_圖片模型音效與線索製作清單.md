## 1. 美術基準

使用者參考圖的重點是：巨大壓迫性的佛壇、垂落破紅布、粗重木柱、密集燭火與冷色頂光。實機需依現有四層建築尺度調整，不能用一張概念圖取代可走動的場景。

| 項目 | 規格 |
| --- | --- |
| 整體 | 台灣山區廟宇；寫實、潮濕、失修；保留地方木構與供桌語彙 |
| 色彩 | 冷灰青月光、暗紅布、氧化金銅、低飽和褐木；避免整張畫面純紅 |
| 表面 | 可辨識漆層剝落、木紋、潮斑、布纖維、蠟堆與細裂；粗糙度需有變化 |
| 光線 | 火點與月光引導路線；陰影有層次；手電筒可閱讀文字與證物 |
| 佛像 | 各完整神像均蒙眼；主尊、陪祀、羅漢、小佛、土地公不能漏掉 |
| 人物 | 主角第一人稱；童年只在照片／記憶剪影；成年白衣女影為借聲者模仿母親 |
| UI | 紙本筆記、舊相片、細紅線與簡潔繁體字幕；不用發光科幻介面 |

## 4. 角色模型細項

### 4.1 主佛與陪祀佛

- 主佛需要可單獨控制的頭部節點、蒙眼布、後腦打結、兩條布尾。
- 坐姿不能只靠圓球堆疊：袈裟大褶方向、肩臂比例、手指、膝與蓮座交界須精修。
- 金屬有舊金箔與暗底漆，粗糙度不均；腐蝕集中在接縫與潮濕處。
- 主尊可使用較高細節；大量小佛用實例化和共享材質，不能每尊獨立載入大貼圖。
- 轉頭只動頭及其眼布；不能轉頭後眼布留在空中。
- 立體背光、蓮瓣與局部雕飾可以程序化；高品質掃描只能在授權、形制與性能適合時替換。

### 4.2 白衣女影／借聲者

- 成年女性體態，長髮覆面、髮縷能形成層次，不能整顆黑球。
- 連身長裙以布褶塑形，袖口與手腕可見；左腕紅線是重要識別。
- 不用誇張性感服裝。恐怖來自不自然的停頓與動作。
- 最低動畫集合：靜止呼吸、頭側偏、抬頭、貼地緩移、追逐、抓取失敗淡黑、退散。
- 近景使用實際 3D 模型；遠距可使用帶透明的圖像幻影，但必須在資產文件中說明。
- 可輸出 GLB 供後續工具使用；程序化骨節／裙擺動畫不是專業真人動作捕捉，不能混稱。

### 4.3 小雨

- 首版以照片、記憶剪影、最後抱兔側影完成；不必製作完整可近看面部。
- 結局表情應平靜、有疲憊感，不做全白眼、裂嘴、血淚等與角色定位矛盾的造型。
- 鬼怪追逐用成年借聲女影，避免把受害女孩同時畫成捕食怪物而沒有說明。

## 5. 材質與性能目標

以下是製作預算，需以目標硬體實測，不代表現有程式已達標。

| 類別 | 建議規模 | 注意事項 |
| --- | --- | --- |
| 主佛 | 約 50k–150k 三角面，2K PBR，近景可提高 | 主尊少量高精度，避免每一層都同時開高細節 |
| 女影 | 約 20k–60k 三角面，2K 身體／衣物材質 | 頭髮透明片要控制疊層；初版程序化可較低 |
| 小佛群 | 共享低面數幾何、實例化 | 蒙眼布也實例化，不額外產生數百 draw calls |
| 建築 | 模組化、同材質批次合併 | 保留分區剔除，地下室與地上不要同時照明 |
| 牆木石 PBR | 1K–2K 為主，局部 4K 視需要 | 含 albedo、normal、roughness／AO；不要把陰影烘在 albedo 裡再疊一次 |
| 主視覺圖 | 保留原圖，另可建立顯示用版本 | 概念圖不要每幀重新解碼 |
| 字幕與文件 | DOM 文字、可調字級 | 不把必需文字只留在低解析貼圖 |
| 目標 | 中畫質 1080p 約 45–60 FPS，低畫質可運行 | 以實際 GPU 與場景統計報告；不保證所有裝置 |

重點：高真實感來自材質、比例、打光、細節位置與動畫一致。單純增加解析度不能修正球形佛臉、穿模裙擺或無關的高亮光源。

### 證物互動規格

1. 靠近、面向且未被牆擋住才顯示 E 調查。
2. 首次取得加入筆記；再次調查開同一證物，不重複增加數量。
3. 文件視圖顯示標題、發現地點、正文、玩家筆記；圖片只是其中一部分。
4. 已拿走的實物從場景消失，或留下明確空位；不可仍閃光像沒拿過。
5. 最終選擇前的缺件提示使用上表地點，避免無目標全圖搜尋。
